# Sweet Potato

A browser game built with vanilla HTML, CSS, and JavaScript.

## Run locally
Open `index.html` in a modern browser, or use a local static server.

## Deploy with GitHub Pages
1. Open the repository's **Settings → Pages**.
2. Choose **Deploy from a branch**.
3. Select `main` and `/ (root)`, then save.

## Project structure
- `css/` — visual styles
- `js/core/` — game lifecycle, state, storage, and events
- `js/scenes/` — menu, gameplay, and settings screens
- `js/systems/` — input, audio, score, and level systems
- `js/utils/` — shared helpers
- `assets/` — images, audio, and fonts
- `docs/` — development notes
